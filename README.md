# Cartes PLU Evolis — mises à jour (secours)

Adresse de secours des mises à jour du logiciel Cartes PLU Evolis (Deltinfo Studio), utilisée quand maj.deltinfo.eu ne répond pas.

Chaque version publiée contient `version.json` (signé Ed25519 par Deltinfo Studio) et l’installateur de mise à jour, dont l’empreinte SHA-256 figure dans le manifeste signé. Le logiciel refuse tout fichier non signé ou modifié.

Contact : cgernigon@deltinfo.eu
